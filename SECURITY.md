# Security policy

## Supported versions

Only the latest version on the `main` branch gets fixes.

## How the tool handles your files

The tool runs only in your browser. It does not upload your save backup or send it anywhere, and it does not load any code from other websites.

## Report a security problem

Please do not report security problems in a public issue.

Use GitHub's private reporting instead:

1. Open the [Security tab](https://github.com/TweenzY-Y/nfsu2-xyz-money-editor/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

Only the maintainer can see the report. The maintainer answers as soon as possible.

Security problems in nfsu2.xyz itself are not part of this project. Please report those to nfsu2.xyz.
