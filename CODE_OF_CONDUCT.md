# Code of conduct

This project is a small fan tool for [nfsu2.xyz](https://nfsu2.xyz). Everyone who takes part in it, in issues, pull requests or anywhere else in this repository, should feel welcome.

## What we expect

- Be friendly and patient, also with people who are new to GitHub or who do not speak English well.
- Respect other opinions, and give feedback about the work, not the person.
- Accept feedback, say sorry when you make a mistake, and learn from it.
- Think about what is best for the people who use the tool.

## What is not allowed

- Insults, personal attacks and comments that make fun of someone.
- Sexual language or images, and unwanted sexual attention.
- Harassment in public or in private.
- Sharing someone's private information, such as an address or email, without their permission.
- Anything else that a reasonable person would see as unprofessional.

## What happens if someone breaks these rules

The maintainer can remove or edit comments, commits, issues and pull requests that break this code of conduct. The maintainer can also give a warning, or block someone from the project for a time or for good.

## How to report a problem

If someone breaks these rules, contact the maintainer, [@TweenzY-Y](https://github.com/TweenzY-Y), on GitHub. The maintainer looks at every report and tries to keep the name of the person who reports it private.

## Where this comes from

This code of conduct is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, written in simpler English.
